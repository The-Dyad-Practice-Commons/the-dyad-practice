Each entry = a survived dyadic-cycle (a real correction the discipline survived, none refuting):

1. **The provenance sweep** — renamed a display term by editing ~15 provenance files at once; the Operator

2. **The parallel noun** — minted a second noun ("DNA") for a concept that already had a home (the inherited
   floor), creating a second content-home; the Operator collapsed it as redundant. Fix: one home per fact —
   don't mint a second home for a fact that already has one (move §1).
3. **The restated view** — a new reading-map re-narrated the manifesto's belief and restated its falsifier
   list. The Operator grounded the division: the manifesto owns *what + why*; the map owns *how*. Fix: a
   view points, never restates; one purpose per surface (move §2–3).
4. **The second axis** — found a classification (inherited / built / lived) invisible in the file tree; the
   reflex was to reorganize the directories by it. Refused — kept the one read-path axis physical and
   carried the classification as metadata. Fix: one physicalized axis; orthogonal classifications are
   metadata, not a second hierarchy (move §5).
5. **The premature folder** — tempted to mirror the Commons' `library/` as a *local* folder to gather the
   "built" files. Refused — it pre-draws a boundary that is earned through practice, and duplicates a
   singular Commons collection. Fix: structure earned, not pre-drawn (move §6).

**Pattern:** all five are one drift — a fact or a structure-decision spreading beyond its single earned
home (a duplicate, a swept rename, a restated view, a second hierarchy, a premature folder) — caught in
real use and pulled back to one home; none refuted the discipline. n=1, single-dyad (breadth pending a
non-inheriting second dyad).
